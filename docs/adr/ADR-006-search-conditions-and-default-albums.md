# ADR-006: 検索条件の組み方、12色パレット、既定の自動アルバム

- 状態: 採用
- 作成日: 2026-10-29
- 関連: ADR-005 の未決事項、`design.md` 第9.2節・第9.4節・第9.5節・第15章、T1-11、T2-8、T3-9

## 文脈

ADR-005 で未決とした次の3項目が、T2-8（色検索）と T3-9（自動アルバム）の開始条件になっている。

- 検索条件の組み方
- 12色パレットの HEX 値と距離の閾値
- 既定の自動アルバムの種類

DeepSeek による統合作業（PR #11）では、これらを仮決定のまま扱っていた。

## 決定

### 1. 検索条件の組み方

`design.md` 第9.2節と `ui-contract.md` 第2.6節の方式を採る。タグ条件は「すべて含む」「いずれかを含む」「含まない」の3つのタグ集合で指定し、3つを同時に使える。タグ条件、色条件、属性条件の間は AND で結ぶ。

v2 の「同じカテゴリ内は OR、カテゴリ間は AND」は採らない。この方式は「いずれかを含む」の集合だけを使った場合として表せる。

### 2. 12色パレット

赤・橙・黄・黄緑・緑・水色・青・紫・ピンク・茶・白・黒の12色を、仮の HEX 値と閾値で設定ファイルに置いて実装を進める。灰は白と黒の間を距離で判定する。デザイナーと合意したら、設定ファイルの値だけを差し替える。値の差し替えはコードの変更を伴わない。

### 3. 既定の自動アルバム

次の3つを既定とする。

| 名前 | 条件 |
|---|---|
| 最近追加した画像 | 直近30日に索引へ追加された画像 |
| タグのない画像 | 確定タグが1つもない画像 |
| 未確認の自動タグあり | `suggested` の割当が残っている画像。レビューへの入り口として使う |

DeepSeek が仮決定した「今年撮影した画像」は既定に含めない。ユーザーが同じ条件の自動アルバムを作ることはできる。

## 影響

- T1-11 のタグ条件を、モード1つの指定から3つのタグ集合に改める。`ui-contract.md` 第2.6節に実装を合わせる変更で、契約の意味は変わらない。
- T2-8 と T3-9 の開始条件のうち、パレットの HEX 値の合意だけが残る。仮の値で実装を進めてよい。
- `design.md` 第15章の該当行を更新する。
