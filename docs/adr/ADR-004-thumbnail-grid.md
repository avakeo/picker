# ADR-004: サムネイル配信と均等仮想グリッド

- 状態: 提案
- タスク: T0-6
- 作成日: 2026-09-25
- レイアウト: 均等グリッドのみ
- 計測環境: Apple M5 / 16 GB / macOS 26.6.2 / arm64（計測前提）

## 文脈

1万件規模の画像を、Svelte 5のUIとasset IDだけを受け取るcustom protocolで表示する。今回はユーザー指定により、masonryは比較せず、均等グリッドのみを検証する。

## 計測前に固定した評価基準

この基準を計測前にコミットする。計測結果を見て重みや足切り条件を変更しない。変更する場合は別コミットで理由を記録し、変更後の条件で再計測する。

### 重み

| 評価項目 | 重み |
|---|---:|
| スクロール性能（フレーム時間p95、ドロップフレーム） | 35 |
| メモリ使用量とDOMノード数 | 25 |
| custom protocol境界とasset ID安全性 | 20 |
| 初期表示・追加表示時間 | 10 |
| 実装の複雑度・保守性 | 10 |

### 足切り条件

- 10,000件を読み込んでも、全件をDOMへ生成しないこと
- thumbnail要求にローカルパスを渡さず、asset IDとサイズだけを使うこと
- 通常スクロールでフレーム時間p95が16.7msを超える場合は60fps目標未達として明示する
- スクロール中にUIスレッドをブロックする同期処理を追加しないこと
- 画像欠落・読み込み失敗時にレイアウトが崩れないこと
- 画面幅900px以上で操作可能であること

### 計測条件

- 10,000件の決定的なダミーasset ID
- 画面幅900pxと1440px
- 初期表示、連続スクロール、急速スクロールを各複数回測定
- フレーム時間p50/p95、16.7ms超過率、初期表示時間、DOMノード数、JSヒープまたはプロセスのメモリを記録
- UI契約上のサムネイル要求がasset IDとサイズ以外を受け付けないことを確認

## 計画

`src/t0-6/VirtualGrid.svelte` は固定セルの均等グリッドを行単位で仮想化する。`src/t0-6/gridBenchmark.ts` はブラウザ上でスクロールとフレーム時間を計測する。実機のブラウザ開発者ツールまたはTauri実行時の計測結果をこのADRへ転記する。
