# 日本語検索クエリ作成チェックリスト

20〜30件を目安に、評価写真を見ながら特定候補に有利な表現へ寄せずに作る。各種類を含め、同義語だけで件数を水増ししない。

| 種類 | 目安 | 例 | 確認点 |
|---|---:|---|---|
| 物・人物 | 4〜6 | 犬、赤い車、複数人 | 単体と複数、一般語と具体語を混ぜる |
| 場面・場所 | 4〜6 | 家の中、公園、海辺 | 屋内・屋外、自然・都市を混ぜる |
| 行動・出来事 | 3〜5 | 食事をしている、遊んでいる | 名詞だけでなく動作を含める |
| 色・属性・構図 | 3〜5 | 青い空、接写、夜の写真 | 視覚で判断できる属性にする |
| 複合条件 | 3〜5 | 夕暮れの海辺、雪の中の人 | 2要素以上を組み合わせる |
| 日本語特有の語 | 2〜4 | お花見、紅葉、縁日 | 英訳で意味が薄れる語を含める |
| 雰囲気・主観語 | 2〜4 | 懐かしい、落ち着いた、にぎやか | 採点ぶれが予想される語も少数含める |

固定前に、重複、写真集合に該当例が全くない語、個人名・住所などの機微情報を確認する。`query_en` は英語fallbackの参考値であり、主評価には使わない。
