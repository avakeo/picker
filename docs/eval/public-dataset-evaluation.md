# 公開データセットによる補助評価案

## STAIR Captions + COCO

STAIR Captionsの日本語キャプションをクエリ、対応するCOCO画像を正解として、text-to-image Recall@1/5/10を自動計測する。これはローカル写真のブラインド採点を置き換えず、公開データにおける補助値として別集計する。

- STAIR Captionsの注釈: CC BY 4.0。公式リポジトリのライセンス表示を確認する
- COCO: 画像ごとの権利はFlickr上の各ライセンスに従う。注釈と画像を同一条件とみなさない
- ダウンロードは開発時のみ。`eval-data/public/` またはリポジトリ外へ置き、写真・注釈・モデルをコミットしない
- 取得URL、データ版、ファイルSHA-256、抽出条件、画像欠損数を生データと一緒に記録する
- 権利条件を自動確認できない画像を再配布しない。アプリへの同梱候補にはしない

確認先:

- https://github.com/STAIR-Lab-CIT/STAIR-captions
- https://cocodataset.org/

COCO画像の利用条件確認と大容量ダウンロードを伴うため、今回は手順提案までとし、ユーザー承認なしに補助データを取得しない。
