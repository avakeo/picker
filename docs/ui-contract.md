# ローカル画像管理アプリ（仮称） UI契約仕様書

- バージョン: 0.1（ドラフト）
- 作成日: 2026-09-24
- 関連文書: `design.md`（第5.4節、第5.5節）、`implementation-plan.md`（T0-8）

本書は UI とコアの間の約束事を定義する。UI（仮UI・本番UIとも）は本書に定義されたコマンド・イベント・サムネイル配信だけを使ってコアとやり取りする。本書の内容は初版であり、フェーズ0以降の実装で具体化する。変更の手順は第8章に従う。

---

## 1. 基本方針

1. **3つの経路だけを使う。** コマンド（UI からの要求と応答）、イベント（コアからの通知）、サムネイル配信（カスタムプロトコル）。
2. **型は Rust 側を正とする。** 本書のデータ型は Rust で定義し、TypeScript の型は自動生成する。本書の記述と生成された型が食い違った場合は、本書を正として実装を直すか、本書を更新する。
3. **UI は状態の正本を持たない。** タグの状態、画像の一覧、処理の進捗などの正本はコアにあり、UI はそれを取得・表示するだけとする。UI 側のキャッシュは、イベントを受けて更新または破棄する。
4. **一覧は必ずページ単位で取得する。** 全件を一度に取得するコマンドは設けない。
5. **識別子は不透明な値として扱う。** アセット ID やタグ ID の中身を UI が解釈・生成してはならない。
6. **ファイルパスを UI からコアに渡すのは、ユーザーがダイアログで選んだフォルダを登録するときだけとする。** それ以外はすべて ID で指定する。
7. **表示文字列はコアから返さない。** エラーなどは種別コードで返し、表示文言は UI 側の翻訳キーで決める。ただしタグ名やファイル名などユーザーのデータはそのまま返す。

## 2. 共通データ型

各型の項目と意味を示す。項目名は実装時に英語の識別子として定める。

### 2.1 識別子

| 型 | 意味 |
|---|---|
| アセットID | 画像の実体を指す不透明な値 |
| ロケーションID | 画像ファイルの所在を指す不透明な値 |
| ルートID | 登録フォルダを指す不透明な値 |
| タグID | タグを指す不透明な値 |
| モデルID | 導入済みモデルを指す不透明な値 |
| カーソル | ページ取得の続きを指す不透明な値 |

### 2.2 アセット概要（グリッド表示用）

| 項目 | 意味 |
|---|---|
| アセットID | |
| 幅・高さ | ピクセル単位。向き補正後の値。メイソンリー配置の計算に使う |
| 形式 | JPEG、PNG、HEIC、WebP のいずれか |
| 撮影日時 | EXIF から取得。無い場合は空 |
| サムネイル準備状態 | 未生成 / 生成済み / 生成失敗 |
| 所在状態 | 存在 / オフライン / 欠落 |
| 未確認タグの有無 | 未確認の提案タグが1つ以上あるか |
| 重複の有無 | 完全一致または近似の重複があるか |

### 2.3 アセット詳細（詳細パネル用）

アセット概要の項目に加えて次を持つ。

| 項目 | 意味 |
|---|---|
| 所在の一覧 | ロケーションID、ルートID、ルートからの相対パス、所在状態の組の一覧 |
| ファイルサイズ | バイト単位 |
| EXIF 要約 | 機種、レンズ、露出、ISO、焦点距離、GPS の有無と座標 |
| タグ割当の一覧 | 第2.5節のタグ割当表示の一覧 |
| インデックス状態 | 各処理段階の状態（完了 / 待機中 / 失敗） |

### 2.4 タグ

| 項目 | 意味 |
|---|---|
| タグID | |
| 名前空間 | general / custom / user（将来追加あり） |
| 日本語表示名・英語表示名 | |
| 親タグID | 階層の親。無ければ空 |
| 色 | 任意 |
| エイリアスの一覧 | |
| 付与数 | 確定状態で付与されている画像の数 |
| 学習状態 | custom タグのみ。未学習 / プロトタイプ方式 / ロジスティック回帰、正例数、負例数 |

### 2.5 タグ割当表示

| 項目 | 意味 |
|---|---|
| タグ | タグの要約（ID、名前空間、表示名、色） |
| 状態 | suggested / confirmed / rejected |
| 出どころ | zero_shot / custom_classifier / user（将来追加あり） |
| 確信度 | 0〜1。user の場合は空 |

UI はこの3項目（状態・出どころ・確信度）を利用者が区別できるように表示する責任を持つ。

### 2.6 検索条件

| 項目 | 意味 |
|---|---|
| タグ条件 | 「すべて含む」「いずれかを含む」「含まない」の3つのタグ集合。親タグは子タグを含めて評価する |
| タグ状態条件 | 確定のみ / 未確認を含む / 未確認のみ |
| ルート条件 | 対象とするルートまたはフォルダ |
| 属性条件 | 撮影日時の範囲、形式、寸法の範囲、ファイルサイズの範囲 |
| テキスト | 自然言語またはタグ名。空なら使わない |
| 類似元 | 指定したアセットに似た画像を探す。テキストとは同時に使えない |
| 並び順 | 撮影日時 / 追加日時 / ファイル名 / 関連度（テキストまたは類似元がある場合のみ） |

### 2.7 ページ

| 項目 | 意味 |
|---|---|
| 項目の一覧 | |
| 次のカーソル | 続きがなければ空 |
| 総件数 | 概算でよい。概算かどうかを示すフラグを伴う |

### 2.8 エラー

| 項目 | 意味 |
|---|---|
| 種別コード | 第7章の一覧のいずれか |
| 詳細 | 開発者向けの補足。UI にそのまま表示しない |
| 対象 | 関係するアセットID・タグID・ルートIDなど（任意） |

## 3. コマンド

### 3.1 ライブラリ

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| ルート一覧 | なし | ルートの一覧（ID、パス、表示名、有効/無効、オンライン状態、画像数） | |
| ルート追加 | フォルダのパス | ルート | ダイアログで選ばれたパスのみ。既存ルートの内側・外側との重複はエラー |
| ルート削除 | ルートID | なし | 配下のロケーションを削除。確定タグは他の所在があれば残る |
| ルート有効化切替 | ルートID、有効/無効 | ルート | |
| 再スキャン | ルートID | なし | 差分スキャンを要求する |
| フォルダツリー取得 | ルートID、親フォルダの相対パス | 子フォルダの一覧と各画像数 | 階層は必要な分だけ取得する |

### 3.2 閲覧

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| アセット検索 | 検索条件、カーソル、ページサイズ | アセット概要のページ | グリッド表示の主経路 |
| アセット詳細 | アセットID | アセット詳細 | |
| Finder で表示 | ロケーションID | なし | OS のファイルマネージャで表示する |
| 表示範囲の通知 | 表示中のアセットIDの一覧 | なし | 処理優先度の引き上げに使う。UI はスクロール停止後に間引いて送る |

### 3.3 タグ

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| タグ一覧 | 名前空間（任意）、絞り込み文字列（任意） | タグの一覧 | 階層は親タグIDで表す |
| タグ候補 | 入力途中の文字列 | タグの一覧（上限あり） | 入力補完用。エイリアスも対象 |
| タグ作成 | 名前空間、表示名、親タグID（任意） | タグ | |
| タグ更新 | タグID、変更する項目 | タグ | 表示名、親、色、エイリアス |
| タグ削除 | タグID | なし | 割当も削除 |
| タグ統合 | 統合元タグID、統合先タグID | タグ | 統合元の割当とエイリアスを統合先へ移す |
| タグ付与 | アセットIDの一覧、タグID | なし | 状態は confirmed、出どころは user |
| タグ除去 | アセットIDの一覧、タグID | なし | 確定を取り消す。以後の再提案を防ぐため rejected として扱う |
| 提案の承認 | アセットID、タグID | なし | suggested を confirmed にする |
| 提案の却下 | アセットID、タグID | なし | suggested を rejected にする |
| 取り消し | なし | 取り消した操作の要約 | 直前のタグ操作を1つ戻す |
| custom への切替 | タグID | タグ | user タグを学習対象にする |

### 3.4 検索補助と重複

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| 完全一致の重複一覧 | カーソル | 重複グループのページ | 同一アセットに複数の所在があるもの |
| 近似の重複一覧 | カーソル、類似度のしきい値（任意） | 重複グループのページ | 知覚ハッシュによる |

類似画像検索と自然言語検索は、アセット検索の検索条件（テキスト、類似元）で行う。

### 3.5 レビュー

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| レビュー対象タグの一覧 | なし | タグと未確認件数の一覧 | 未確認の提案があるタグ |
| レビュー候補の取得 | タグID、件数 | アセット概要と確信度の一覧 | 選定方法は設計書 8.5 |
| レビュー結果の送信 | タグID、承認するアセットIDの一覧、却下するアセットIDの一覧 | なし | 一括で記録し、必要なら再学習を起動する |

### 3.6 インデックスとモデル

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| インデックス状態 | なし | 全体の進捗（段階ごとの完了数・待機数・失敗数）、一時停止中かどうか | |
| 一時停止・再開 | 一時停止/再開 | なし | |
| 失敗一覧 | カーソル | 失敗したアセットと種別コードのページ | |
| 失敗の再試行 | アセットIDの一覧（空なら全件） | なし | |
| モデル一覧 | なし | モデルの一覧（種別、バージョン、状態、サイズ、ライセンス） | |
| モデルのダウンロード | モデルID | なし | 進捗はイベントで通知 |
| モデルの切替 | 種別、モデルID | なし | 該当段階が再処理対象になる |

### 3.7 設定とデータ

| コマンド | 入力 | 出力 | 説明 |
|---|---|---|---|
| 設定取得 | なし | 設定値の一覧 | |
| 設定更新 | キーと値 | 設定値 | 値の検証はコアで行う |
| エクスポート | 保存先（ダイアログで選択） | 書き出した件数 | 再生成不可能データの JSON |
| インポート | ファイル（ダイアログで選択） | 取り込んだ件数、照合できなかった件数 | |
| キャッシュ削除 | 対象（サムネイル / 埋め込み / すべて） | なし | 再生成が始まる |
| アプリ情報 | なし | バージョン、ライセンス一覧、モデルのライセンス | 「このアプリについて」画面用 |

## 4. イベント

コアから UI への通知。UI は必要なイベントを購読し、自分のキャッシュを更新する。

| イベント | 内容 | 発生頻度の上限 |
|---|---|---|
| インデックス進捗 | 段階ごとの完了数・待機数・失敗数 | 1秒に数回程度に間引く |
| サムネイル生成完了 | アセットIDの一覧 | まとめて通知する |
| アセット更新 | アセットIDの一覧と変更種別（タグ、所在、メタデータ） | まとめて通知する |
| アセット追加・削除 | アセットIDの一覧 | まとめて通知する |
| ルート状態変化 | ルートIDとオンライン状態 | 変化時 |
| タグ定義の変更 | タグIDの一覧と変更種別（作成、更新、削除、統合） | 変化時 |
| 再学習完了 | タグIDと新しい学習状態 | 変化時 |
| モデルのダウンロード進捗 | モデルID、進捗率、状態（進行中、完了、失敗、検証失敗） | 1秒に数回程度に間引く |
| 通知 | エラー種別コードまたは情報種別と対象 | 発生時 |

イベントは取りこぼしがあり得る前提で扱う。UI はウィンドウの再表示時などに、必要な一覧を取り直すことで整合を回復する。

## 5. サムネイル配信

- アプリ専用のカスタムプロトコルで配信する。指定できるのはアセットIDとサイズ（グリッド用 / 詳細用）だけとする。
- サムネイルが未生成の場合は「未生成」を示す応答を返す。UI はプレースホルダを表示し、サムネイル生成完了イベントを受けてから取り直す。
- 生成に失敗している場合は「失敗」を示す応答を返し、UI は失敗用の表示にする。
- 応答にはキャッシュ可能であることを示す情報を付ける。サムネイルが再生成された場合に UI 側のキャッシュが古くならないよう、取得先にはバージョン情報を含める。
- 原寸画像の表示は MVP では詳細用サムネイルで代替する。原寸表示が必要になった場合は、同じ方式でサイズの種類を追加する。

## 6. 性能上の約束

- アセット検索の1ページは、既定で数百件程度とする。UI は必要な範囲だけを追加で取得する。
- 表示範囲の通知は、スクロールが止まってから短い間隔をおいて送る。スクロール中に連続で送らない。
- コマンドは UI スレッドをブロックしない。時間のかかる処理（再スキャン、エクスポート、再学習）はすぐに応答を返し、完了や進捗はイベントで通知する。
- イベントは第4章の頻度上限を守り、UI が処理しきれない量を送らない。

## 7. エラー種別コード（初版）

| 種別 | 意味 |
|---|---|
| 見つからない | 指定した ID の対象が存在しない |
| 入力不正 | 入力値が仕様に合わない |
| ルート重複 | 既存ルートの内側または外側のフォルダを登録しようとした |
| アクセス不可 | フォルダやファイルを読めない |
| オフライン | 対象のルートがオフライン |
| 形式非対応 | 対応していない画像形式 |
| 上限超過 | サイズ・画素数・処理時間の上限を超えた |
| デコード失敗 | 画像を読み込めない |
| モデル未導入 | 必要なモデルがダウンロードされていない |
| モデル検証失敗 | ダウンロードしたモデルのハッシュが一致しない |
| 取り消し不可 | 取り消せる操作がない |
| 内部エラー | 上記以外。詳細はログに記録する |

## 8. 変更の手順

1. 契約の追加・変更は、本書の更新と実装を同じ PR で行う。
2. 既存のコマンド・イベント・型の意味を変える変更や、項目の削除は「互換性を壊す変更」とし、ADR に理由を記録する。
3. 本番UI（MD）の実装中にデザインが契約にない情報を必要とした場合は、先に本書の変更を提案し、コア側を対応してから UI を実装する。
4. 契約テストは、本書の各コマンドについて正常系と主なエラー系を検証する。
